# 01. Domain Entities & Core Structures

Located primarily in `src/domain/entities.py`, the Domain models represent the absolute core of SYNAPSE's business logic. All components (UI, PyTorch models, gRPC clients) depend on these structures, enforcing the Dependency Inversion Principle.

## Topological Entities (The World)

SYNAPSE models the urban environment based on the SUMO `.net.xml` specification, but distills it into memory-efficient Dataclasses.

### `MapNode`
Represents an intersection.
- **Attributes**: `id`, `x`, `y`, `node_type`, `tl_logic_id` (The Traffic Light ID linking it to CARINA).
- **Function**: During the Graph Attention phase (GATv2), `MapNode`s act as the vertices holding the temporal embeddings generated by the TCNs.

### `MapEdge`
Represents a road segment connecting two intersections.
- **Attributes**: `id`, `from_node`, `to_node`, `shape` (Geometry), `weight`, `signal_group_id`.
- **Function**: `MapEdge`s dictate the flow of attention in the spatial reasoning model. A traffic jam on an edge will propagate mathematically to the `from_node`.

## Ingestion Entities (The Senses)

### `DataSource`
The most critical entity in the ingestion pipeline. It represents a physical camera, a radar, or a global API (Waze). It is built as a flexible data bag:
```python
@dataclass
class DataSource:
    id: str
    name: str
    source_type: SourceType
    is_local: bool
    status: SourceStatus
    latest_value: Any
    semantic_type: Optional[str]
    confidence_score: float
    metadata: Dict[str, Any] # Flexible JSON bag for varying sensor APIs
```

## The Zero-Trust Security Pipeline

SYNAPSE operates in a hostile urban environment. Sensors can be hacked or broken. 

### `SourceStatus` State Machine
A `DataSource` transitions strictly through these states:
1. **`QUARANTINE`**: Initial state. Data is buffered but blocked from the Graph Memory.
2. **`VALIDATING`**: The Linguist Agent is actively processing the buffered data through the NeuroSymbolic model.
3. **`ACTIVE`**: Validation passed. Data flows to the Graph Memory.
4. **`FALLBACK`**: The sensor stopped sending data or sent anomalous data (caught by the Auditor). System defaults to KSE/MEH.
5. **`PROBATION`**: Sensor came back online, but must re-prove its reliability before returning to `ACTIVE`.
6. **`REJECTED`**: Caught sending malicious/impossible physics. Permanently blocked.

### Trust Score Constants
When resolving conflicts (e.g., Waze says traffic is stopped, but the local camera says it is flowing), the system uses hardcoded Bayesian priors:
- `LOCAL_TRUST_SCORE = 0.95` (Physical sensors have the right of way).
- `GLOBAL_TRUST_SCORE = 0.60` (Crowdsourced APIs are prone to lag and user error).
